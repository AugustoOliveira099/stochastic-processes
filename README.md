# Processos Estocásticos - PPgEEC/UFRN

Este repositório contém material desenvolvido para a disciplina de **Processos Estocásticos** do Programa de Pós-graduação em Engenharia Elétrica e de Computação (PPgEEC) da Universidade Federal do Rio Grande do Norte (UFRN), ministrada pelo Prof. Dr. Allan de Medeiros Martins no período 2024.2.

## 📚 Sobre o Repositório

O repositório reúne anotações de aula, código de análise e um relatório técnico aplicando os conceitos de processos estocásticos à análise de sinais sonoros de aerogeradores.

## 📂 Estrutura do Repositório

- **`Anotacoes_unidade-1.pdf`**: Anotações das aulas da Unidade 1
- **`Anotacoes_unidades-2-e-3.pdf`**: Anotações das aulas das Unidades 2 e 3
- **`Processos_estocasticos_relatorio.pdf`**: Relatório técnico aplicando os conceitos aprendidos na disciplina à análise de sinais sonoros de aerogeradores
- **`Codigo_para_relatorio_processos_estocasticos.ipynb`**: Notebook Jupyter com o código desenvolvido para análise dos dados e geração dos resultados apresentados no relatório

## 🎯 Objetivo

O trabalho prático desenvolvido durante a disciplina teve como objetivo aplicar os conceitos de processos estocásticos na análise de sinais sonoros provenientes de aerogeradores, explorando técnicas de caracterização estatística e análise espectral de processos aleatórios.

## 🛠️ Tecnologias Utilizadas

- Python
- Jupyter Notebook
- Bibliotecas: NumPy, Matplotlib, Librosa (processamento de áudio), entre outras
